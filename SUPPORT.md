# Support

Use [GitHub Issues](https://github.com/Luizinfo/IdentityModel/issues) for reproducible bugs, feature proposals, and documentation problems concerning ZinfoFramework.IdentityModel.

Before opening an issue, search existing reports and include the package version, target framework, minimal reproduction, expected behavior, and actual behavior. This community project does not provide a support SLA. For vulnerabilities, use the private process in [SECURITY.md](SECURITY.md).
