# Contributing

Contributions to ZinfoFramework.IdentityModel are welcome.

1. Search the [current repository issues](https://github.com/Luizinfo/IdentityModel/issues) before opening a new issue.
2. For a code change, target .NET 10, preserve the `IdentityModel` assembly and namespaces, and add or update tests.
3. Run `dotnet restore`, `dotnet build -c Release`, and `dotnet test -c Release` before submitting a pull request.
4. Describe the problem, behavior change, compatibility impact, and validation performed.

Do not report security vulnerabilities in a public issue; follow [SECURITY.md](SECURITY.md).
